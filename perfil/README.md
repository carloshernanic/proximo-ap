# perfil/

Seus dados pessoais ficam aqui e **não vão para o git** (veja `.gitignore`).

O `/setup` copia os modelos de `templates/perfil/` para cá e preenche com as suas
respostas:

- `preferencias.md` — o que você procura (bairros, orçamento, imóvel, pesos)
- `buscas.md` — as buscas concretas que o `/scrape` roda em cada portal
